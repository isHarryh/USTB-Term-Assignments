# 七种排序算法的时间与空间复杂度分析

## 一、引言

本报告以算法分析为视角，对七种经典排序算法进行时间和空间复杂度分析。

### 1.1 记号

- 用 $n$ 表示待排序的元素个数，$K$ 表示计数排序中元素的取值范围大小，$d$ 表示基数排序中元素的位数，$b$ 表示基数（进制的底数）。
- 用 $T(n)$ 表示算法的原子操作次数，$O$、$\Omega$、$\Theta$ 采用渐近意义下的标准定义。

### 1.2 约定

- 比较、交换、赋值、算术运算与数组访问等均视为单次原子操作。
- 平均情况是指输入为 $n$ 个互异元素的所有 $n!$ 种排列等可能地出现。
- 空间复杂度只统计辅助空间；递归算法的调用栈也计入辅助空间。
- 稳定性指排序后相等元素的相对次序保持不变。

## 二、平方阶的比较排序算法

冒泡排序、选择排序与插入排序都只通过元素间的大小比较决定次序，且时间复杂度在最坏情况下均为 $\Theta(n^2)$，因此放在一起讨论。

### 2.1 冒泡排序

**伪代码**

```txt
BUBBLE-SORT(A, n)
  for i = 1 to n-1
      swapped = false
      for j = 1 to n-i
          if A[j] > A[j+1]
              swap(A[j], A[j+1])
              swapped = true
      if swapped == false
          break
```

**时间复杂度**

最坏情况为输入完全逆序。此时每一趟都会发生交换，提前退出标志永远无法生效。第 $i$ 趟进行 $n-i$ 次比较，总比较次数为

$$T(n) = \sum_{i=1}^{n-1}(n-i) = \frac{n(n-1)}{2} = \Theta(n^2)$$

最好情况为输入已经有序。第一趟进行 $n-1$ 次比较后没有任何交换，算法随即因早停条件而结束，此时

$$T(n)=n-1=\Theta(n)$$

平均情况下，设初始逆序对数量为 $I$，则每次交换恰好消去一个逆序对，排序完成时 $I=0$，因此交换次数恰好等于初始逆序对数；另一方面，每次比较至多引起一次交换，故比较次数不小于交换次数。对于随机排列，任意一对元素形成逆序对的概率为 $1/2$，则有

$$E[I] = \frac{1}{2}\binom{n}{2} = \frac{n(n-1)}{4} = \Theta(n^2)$$

于是平均比较次数为 $\Theta(n^2)$。

**空间复杂度**

只需常数个临时变量用于交换与标志位，辅助空间为 $O(1)$，是原地排序。

**稳定性**

相邻元素相等时不交换，即相等元素的相对次序不会改变，故冒泡排序稳定。

### 2.2 选择排序

**伪代码**

```txt
SELECTION-SORT(A, n)
  for i = 1 to n-1
      min = i
      for j = i+1 to n
          if A[j] < A[min]
              min = j
      swap(A[i], A[min])
```

**时间复杂度**

内层循环只负责寻找当前区间的最小元素，其比较次数与输入顺序完全无关：

$$T(n) = \sum_{i=1}^{n-1}(n-i) = \frac{n(n-1)}{2} = \Theta(n^2)$$

最好、平均、最坏三种情况均为 $\Theta(n^2)$。选择排序的优点是交换次数少（不超过 $n-1$ 次），在交换代价远高于比较代价的场合仍有价值。

**空间复杂度**

$O(1)$，原地排序。

**稳定性**

不稳定。反例：对 $[2_1, 2_2, 1]$ 排序，第一趟把最小值 $1$ 与首元素 $2_1$ 交换，得到 $[1, 2_2, 2_1]$，两个 $2$ 的相对次序被颠倒。

### 2.3 插入排序

**伪代码**

```txt
INSERTION-SORT(A, n)
  for i = 2 to n
      key = A[i]
      j = i-1
      while j >= 1 and A[j] > key
          A[j+1] = A[j]
          j = j-1
      A[j+1] = key
```

**时间复杂度**

设初始逆序对数量为 $I$。内层循环每右移一个元素恰好消去一个逆序对，因而移位次数恰为 $I$；每次进入循环体前还要做一次比较，且每个 $i$ 至多因下标越界而多做一次失败比较，故比较次数介于 $I$ 与 $I+n$ 之间。因此

$$T(n) = \Theta(n + I)$$

最坏情况（完全逆序）：$I=\binom{n}{2}=\frac{n(n-1)}{2}$，故 $T(n)=\Theta(n^2)$。

最好情况（已经有序）：$I=0$，故 $T(n)=\Theta(n)$。

平均情况：与冒泡排序同理，$E[I]=\frac{n(n-1)}{4}$，故 $T(n)=\Theta(n^2)$。

**空间复杂度**

$O(1)$，原地排序。

**稳定性**

采用 $A[j] > key$ 的严格比较并整体右移，相等元素不会越过彼此，故插入排序稳定。在平方阶算法中，插入排序通常是实际运行最快的一种。

## 三、基于分治策略的排序算法

归并排序与快速排序都采用分而治之（Divide and Conquer）策略：把大问题划分为子问题，递归求解后再合并，从而达到 $\Theta(n\log n)$ 量级。

### 3.1 归并排序

**伪代码**

```txt
MERGE-SORT(A, p, r)
  if p < r
      q = floor((p+r)/2)
      MERGE-SORT(A, p, q)
      MERGE-SORT(A, q+1, r)
      MERGE(A, p, q, r)     // 合并两个有序子数组

MERGE(A, p, q, r)
  // 依次取两段子数组头部的较小者写入辅助数组，最后复制回 A
```

**时间复杂度**

设 $T(n)$ 为排序 $n$ 个元素的代价。划分本身的代价为 $\Theta(1)$；合并需要完整扫描两段子数组，代价为 $\Theta(n)$，于是得到递归式

$$T(n) = 2T\left(\frac{n}{2}\right) + cn, \qquad T(1) = \Theta(1)$$

第 $k$ 层（从 $0$ 开始计数）共有 $2^k$ 个子问题，每个子问题的规模为 $n/2^k$，该层总代价为 $2^k \cdot c\dfrac{n}{2^k} = cn$；递归在子问题规模降为 $1$ 时终止，共 $\log_2 n + 1$ 层。因此

$$T(n) = cn(\log_2 n + 1) = \Theta(n\log n)$$

无论输入顺序如何，合并过程都要完整扫描并复制全部元素，故最好、平均、最坏三种情况均为 $\Theta(n\log n)$。

**空间复杂度**

合并需要一个长度不超过当前子数组规模的辅助数组。若逐层分配，同一递归路径上活跃的辅助空间之和不超过

$$n + \frac{n}{2} + \frac{n}{4} + \cdots < 2n = \Theta(n)$$

递归栈深度为 $\Theta(\log n)$，因此总辅助空间为 $\Theta(n)$。归并排序不是原地排序。

**稳定性**

合并时若两段头部元素相等，优先取左段元素，即可保持相等元素的原有次序，故归并排序稳定。

### 3.2 快速排序

**伪代码**

```txt
QUICKSORT(A, p, r)
  if p < r
      q = PARTITION(A, p, r)
      QUICKSORT(A, p, q-1)
      QUICKSORT(A, q+1, r)

PARTITION(A, p, r)            // 取首元素 A[p] 为轴
  pivot = A[p]
  i = p
  for j = p+1 to r
      if A[j] <= pivot
          i = i+1
          swap(A[i], A[j])
  swap(A[p], A[i])
  return i
```

**时间复杂度**

每次划分的代价为 $\Theta(n)$，算法的整体代价取决于划分的均衡程度。

最好情况：每次划分恰好将区间等分，递归式为 $T(n)=2T(n/2)+\Theta(n)$，与归并排序相同，得 $T(n)=\Theta(n\log n)$。

最坏情况：以首元素为轴时，若输入已经有序或完全逆序，每次划分都得到 $0$ 与 $n-1$ 的极端不平衡分割，递归式退化为

$$T(n) = T(n-1) + \Theta(n)$$

逐层累加得 $T(n)=\Theta(n^2)$。

平均情况：推导较为复杂。设首元素作为轴，其秩在 $\{0,1,\dots,n-1\}$ 上均匀分布，并利用递归定义即可推出。这里直接给出结论，$T(n)=(n+1)\cdot\Theta(\log n)=\Theta(n\log n)$。

**空间复杂度**

划分在原数组内完成，不需要额外数组；辅助空间主要来自递归调用栈：最好与平均情况栈深为 $\Theta(\log n)$，最坏情况栈深为 $\Theta(n)$。

**稳定性**

不稳定。反例：对 $[2_1, 2_2, 1]$ 排序，取首元素为轴，划分后得到 $[1, 2_2, 2_1]$，两个 $2$ 的相对次序被颠倒。

## 四、非比较排序算法

计数排序与基数排序不依赖元素间的大小比较，而是利用键的整数结构与取值范围获取信息，因此可以突破比较排序的下界。

### 4.1 计数排序

**伪代码**

```txt
COUNTING-SORT(A, n, K)        // 键为 [0, K) 内的整数
  C[0..K-1] = 0
  for i = 1 to n: C[A[i]] += 1
  for v = 1 to K-1: C[v] += C[v-1]
  for i = n downto 1
      B[C[A[i]]] = A[i]
      C[A[i]] -= 1
  return B
```

**时间复杂度**

第一个循环统计频次需 $\Theta(n)$，第二个循环求前缀和需 $\Theta(K)$，第三个循环按计数把元素放回输出数组需 $\Theta(n)$，合计

$$T(n,K) = \Theta(n+K)$$

算法的代价只取决于元素个数 $n$ 与键范围 $K$，与输入顺序无关，故最好、平均、最坏三种情况相同。当 $K=O(n)$ 时，$T(n)=\Theta(n)$，达到线性时间。

**空间复杂度**

计数数组 $C$ 的长度为 $K$，输出数组 $B$ 的长度为 $n$，共需 $\Theta(n+K)$ 辅助空间，不是原地排序。

**稳定性**

从后往前遍历输入，并结合前缀和定位输出下标，可以保证相等元素的相对次序不变，故计数排序稳定。

### 4.2 基数排序

**伪代码**

```txt
RADIX-SORT(A, n, d)           // d 位十进制非负整数
  for k = 1 to d              // 从最低位到最高位
      用计数排序按第 k 位稳定地排序 A
```

**时间复杂度**

每一趟按一位数字排序，使用 $b=10$ 个桶，则以计数排序实现单趟的代价为 $\Theta(n+b)$。共 $d$ 趟，故

$$T(n,d) = \Theta\big(d(n+b)\big)$$

对取值范围为 $[0,K)$ 的键，位数 $d=\lceil\log_b K\rceil$。与计数排序一样，基数排序的代价与输入顺序无关，最好、平均、最坏三种情况相同。

**空间复杂度**

每趟需要一个长度为 $b$ 的计数数组和一个长度为 $n$ 的输出数组，共 $\Theta(n+b)$ 辅助空间，不是原地排序。

**稳定性**

基数排序的正确性建立在"逐位稳定"之上：低位排序的结果必须被高位排序保持，因此每趟排序都必须稳定，算法整体也是稳定的。

## 五、综合对比与结论

将七种算法的主要结论汇总如下表（$n$ 为元素个数，$K$ 为计数排序的键范围，$d$ 为基数排序的位数，$b$ 为基数）：

| 算法     | 最好情况          | 平均情况          | 最坏情况          | 辅助空间                        | 稳定性 | 原地 |
| -------- | ----------------- | ----------------- | ----------------- | ------------------------------- | ------ | ---- |
| 冒泡排序 | $\Theta(n)$       | $\Theta(n^2)$     | $\Theta(n^2)$     | $O(1)$                          | 稳定   | 是   |
| 选择排序 | $\Theta(n^2)$     | $\Theta(n^2)$     | $\Theta(n^2)$     | $O(1)$                          | 不稳定 | 是   |
| 插入排序 | $\Theta(n)$       | $\Theta(n^2)$     | $\Theta(n^2)$     | $O(1)$                          | 稳定   | 是   |
| 归并排序 | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n)$                     | 稳定   | 否   |
| 快速排序 | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n^2)$     | $\Theta(\log n)$ \~ $\Theta(n)$ | 不稳定 | 是   |
| 计数排序 | $\Theta(n+K)$     | $\Theta(n+K)$     | $\Theta(n+K)$     | $\Theta(n+K)$                   | 稳定   | 否   |
| 基数排序 | $\Theta(d(n+b))$  | $\Theta(d(n+b))$  | $\Theta(d(n+b))$  | $\Theta(n+b)$                   | 稳定   | 否   |

综合来看：

- **平方阶算法**（冒泡、选择、插入）实现简单、辅助空间为常数，适合小规模数据；其中插入排序通常是实际运行最快的平方阶算法，选择排序的交换次数最少。
- **分治算法**（归并、快速）在一般情况下达到比较排序的下界 $\Theta(n\log n)$：归并排序性能稳定且天然稳定，代价是需要 $\Theta(n)$ 的辅助空间；快速排序原地划分、常数因子小，但最坏情况会退化到 $\Theta(n^2)$，且不稳定。
- **非比较算法**（计数、基数）利用键的整数结构绕过了 $\Omega(n\log n)$ 下界，在键范围合适时可达到线性或接近线性的时间，代价是需要额外的计数/桶空间，且只适用于整数等结构化的键。

因此，算法选择不存在唯一答案：**数据规模、键的性质、对稳定性与空间的要求**，共同决定了哪种排序算法才是合适的。
