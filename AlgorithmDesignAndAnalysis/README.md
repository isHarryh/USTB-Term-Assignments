# Algorithm Design and Analysis

本文件夹是《算法设计与分析》课程的作业内容。

## 作业

### 作业主题

1. **作业 1**：插入排序及选择排序的代码实现。
2. **作业 2**：七种排序算法的时间与空间复杂度分析。
3. **作业 3**：Qwen3.6-35B-A3B 模型各层参数量的计算与分析。
4. **作业 4**：用分治法实现归并排序、最大子数组和快速排序，并分析其递归过程。
5. **作业 5**：用动态规划求解 0-1 背包问题和最大子数组问题。
6. **作业 6**：用贪心法求解部分背包问题和霍夫曼编码，并分别用贪心法和动态规划求解活动选择与带权活动选择问题。
7. **作业 7**：基于邻接表实现无向图的广度优先遍历和深度优先遍历。
8. **作业 8**：实现有环判定、强连通分量，以及最小生成树的 Prim 算法和 Kruskal 算法。
9. **作业 9**：实现单源最短路径（Dijkstra）、最大二分匹配（匈牙利算法）和最大流（Ford-Fulkerson）。
