# 人工智能基础A 实验指导书

## 一、实验目的

使用 C/C++ 语言编写程序，解决迷宫搜索问题。

本实验基于状态空间搜索算法，快速找到迷宫的出口。通过演示，可以清楚地展示基于状态空间搜索算法的工作流程，同时提供自动寻找路径的功能。

## 二、实验内容

1. 以走迷宫为例设计基于状态空间搜索算法；
2. 画出算法求解框图；
3. 分析算法的特点。

## 三、实验原理

盲目搜索策略需要事先预定的控制策略进行搜索，在搜索过程中不使用中间信息改变控制策略。

启发式搜索需要在搜索过程中加入与问题相关的启发性信息，预定义好合适的启发函数，缩小问题的搜索范围，指导搜索朝着最有希望方向前进，尽快找到问题的最优解。

## 四、实验要求

程序应该使用 A* 搜索算法完成，代价函数自定。

程序在控制台应该显示出以下内容：

1. 在迷宫中标注 Open 表中的最后的节点；
2. 在迷宫中标注 Closed 表中的最后的节点；
3. 在迷宫中标注出从起点到终点的路径。

## 五、实验报告要求

1. 搜索算法流程图和算法框架。
2. 分析启发式搜索的特点。
