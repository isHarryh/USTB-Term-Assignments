# DataStructure

本文件夹是《数据结构基础》课程的作业代码和实验代码，采用 Go 语言实现。

其中 `cmd/weekX_test.go` 是第 X 周作业的代码；`cmd/expX/` 文件夹内是第 X 次实验的代码。此外，在 `pkg/` 文件夹内存放有一些公用实现。

## 作业

### 作业主题

共 2 周作业，题目分别是：

1. 顺序表相关的简单应用。
2. 链表相关的简单应用。

## 实验

### 实验主题

共 3 次实验，题目分别是：

1. 求相邻节点之和最大的第一节点。
2. 汉诺塔问题。
3. 哈夫曼编码。

### 实验报告要求

每次实验的实验报告需要包括以下章节：

1. 实验目的：描述本实验练习的知识点、希望掌握的内容和技能。
2. 实验内容：给出该实验对功能、输入、输出等的描述及要求。
3. 问题分析与算法思路：通过对问题进行分析，得出求解问题的算法思路。包括问题分析的过程、适合采用的数据结构、算法思路。在算法设计中体现创新意识，比如能综合考虑时空权衡等。
4. 算法描述：用伪代码给出算法描述。
5. 程序实现：给出完整的程序源代码和注释（参见具体代码文件），说明在程序实现中对用户的友好性、程序的模块化和扩展性等是如何考虑的。
6. 测试：说明测试的思路，是如何验证在不同输入下（包括边界情况）程序正确性的；给出测试用例和测试结果。
7. 算法的有效性分析：分析算法的时间复杂度、空间复杂度、有效性、不足和改进意见。如果同时采用了多种实现方法，进行对比说明、分析。
