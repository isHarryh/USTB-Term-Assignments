# 实验 1 报告：求相邻节点之和最大的第一节点

## 1. 实验目的

- 复习并掌握链表的创建与基本操作（插入、按位访问）。
- 练习在给定输入格式下完成链表构建与遍历处理。
- 理解相邻元素关系的处理方法，并能分析算法复杂度。

## 2. 实验内容

给定一组整数序列，以 0 为结束标志。基于输入构造链表，找到相邻两个结点之和最大的那一对，并输出该对中**第一个结点**的值。若有效数据不足（0 之前不足两个元素），应给出提示或判定为无效输入。

输入要求：
- 以空白分隔的整数序列，必须以 0 结束。

输出要求：
- 输出相邻和最大的那一对的第一个结点值。

## 3. 问题分析与算法思路

题目本质是对线性结构中相邻元素的扫描。链表适合顺序构建，但按位访问需要依赖链表的 `Get` 操作。思路如下：

1. 从输入序列构建链表，遇到 0 停止。
2. 若链表长度小于 2，直接判无效。
3. 依次考察相邻位置 $i$ 和 $i+1$ 的元素和，记录最大和及其对应的第一个结点值。
4. 输出记录的结点值。

该实现复用已提供的链表结构与基础操作，逻辑清晰，易于验证。

## 4. 算法描述（伪代码）

```text
CreateList(input):
    L <- new linked list
    for each v in input:
        if v == 0: break
        L.insert(v, L.length)
    return L

AdjMax(L):
    if L is nil or L.length < 2: return (0, false)
    maxSum <- L.get(0) + L.get(1)
    maxFirst <- L.get(0)
    for i from 1 to L.length - 2:
        sum <- L.get(i) + L.get(i+1)
        if sum > maxSum:
            maxSum <- sum
            maxFirst <- L.get(i)
    return (maxFirst, true)
```

## 6. 测试

测试思路：

- 覆盖边界情况：数据不足两个元素或缺少结束标志。

## 7. 算法有效性分析

- 时间复杂度：链表 `Get(i)` 为线性访问，循环内多次调用导致总复杂度为 $O(n^2)$。
- 空间复杂度：链表存储 $n$ 个元素，额外变量为常数，整体 $O(n)$。
- 有效性：在输入格式正确、元素数量充分时能正确返回目标值。
- 不足与改进：若改为一次遍历并保存前一结点值，可将时间复杂度优化为 $O(n)$，或者使用顺序表存储后再线性扫描。
