# 实验 2 报告：汉诺塔问题

## 1. 实验目的

- 掌握递归求解汉诺塔问题的基本思想。
- 理解递归分解与组合的过程，并能实现输出步骤。
- 学会对递归算法的时间复杂度进行分析。

## 2. 实验内容

输入一个正整数 $n$，表示有 $n$ 个圆盘。按汉诺塔规则，将圆盘从 A 柱移动到 C 柱，B 柱为辅助。输出移动的每一步，并在最后输出总步数。

输入要求：
- 单个正整数 $n$。

输出要求：
- 逐步输出移动序列，格式为：`Step k: Move disk d from X to Y`
- 最后一行输出总步数：`Total moves: m`

## 3. 问题分析与算法思路

汉诺塔问题的递归结构清晰：

- 将前 $n-1$ 个圆盘从 A 移到 B（借助 C）。
- 将第 $n$ 个圆盘从 A 移到 C。
- 将前 $n-1$ 个圆盘从 B 移到 C（借助 A）。

递归边界为 $n=1$，直接移动一次即可。每次递归记录移动步骤，最终得到完整序列。

## 4. 算法描述（伪代码）

```text
SolveHanoi(n):
    if n < 1: error
    moves <- empty list

    function solve(disk, from, aux, to):
        if disk == 1:
            append Move(1, from, to)
            return
        solve(disk-1, from, to, aux)
        append Move(disk, from, to)
        solve(disk-1, aux, from, to)

    solve(n, 'A', 'B', 'C')
    return moves
```

程序主体在 [cmd/exp2/exp2.go](cmd/exp2/exp2.go)，输入输出处理在 [cmd/exp2/main/main.go](cmd/exp2/main/main.go)。实现要点：

- 输入校验：$n < 1$ 返回错误。
- 输出时按顺序打印每一步，并在末尾输出总步数。

## 6. 测试

测试思路：
- 对小规模 $n$ 验证移动步数与关键步骤。
- 验证第一步与最后一步是否符合递归解的结构。

已实现用例：

- 输入：$n = 3$
- 期望总步数：$2^3 - 1 = 7$
- 期望第一步与最后一步均为从 A 到 C 的移动（对应递归结构）。

对应测试代码在 [cmd/exp2/exp2_test.go](cmd/exp2/exp2_test.go)。

建议补充的边界测试：
- 输入：$n = 1$，应仅输出一步。
- 输入：$n = 0$ 或负数，应返回错误。

## 7. 算法有效性分析

- 时间复杂度：递归关系 $T(n) = 2T(n-1) + O(1)$，故 $T(n) = O(2^n)$。
- 空间复杂度：递归深度为 $n$，额外空间为 $O(n)$，加上输出序列长度 $2^n - 1$。
- 有效性：算法严格遵循汉诺塔规则，保证每一步合法。
- 不足与改进：当 $n$ 较大时，输出规模指数增长。若只需步数，可改为直接计算 $2^n - 1$，避免存储序列。
